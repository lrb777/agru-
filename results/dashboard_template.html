模型原理

核心思路

使用与截面选股相同的 AGRU 模型（Attention + GRU），但采用"个股样本 + 市场标签"的训练方式：网络结构和特征不变，训练样本仍为个股样本，但标签从"个股未来收益"替换为"市场未来收益"（中证全指未来1日收益三分类），使模型从个股特征中学习大盘方向。

AGRU 模型结构

输入 (B, 20, 40) # batch × 时序窗口 × 特征数 ↓ Linear(40→64) + Tanh # 特征编码 ↓ GRU(2层, hidden=64) # 时序编码 ↓ ┌─────────────────────────────────────┐ │ gru_last (B,64) [旁路] │ │ Attention(gru_seq) (B,64) │ └─────────────────────────────────────┘ ↓ 融合: [Mul, Sum, Concat] (B, 256) ↓ Dropout(0.3) → Linear(256→64) → Tanh → Linear(64→3) ↓ 三分类输出 (0=空仓 / 1=半仓 / 2=满仓)

训练与信号生成流程

滚动训练：每年滚动，8年训练 + 2年验证 + 1年测试，共7折（2020-2026）。
样本：每日每只股票一个样本（过去20日特征序列），同一交易日内所有股票共享同一市场标签。
信号聚合：每日将全市场个股预测的概率均值聚合为单一择时信号，按验证集分位数阈值映射为 0/1/2。

AGRU 模型 (src/model.py)

class AGRU(nn.Module):
    """Linear→Tanh→GRU→Attn→Mul/Sum/Concat→Linear→Output"""
    def __init__(self, input_dim, hidden_dim=64, num_gru_layers=2,
                 num_classes=3, dropout=0.3):
        super().__init__()
        self.encoder = nn.Sequential(nn.Linear(input_dim, hidden_dim), nn.Tanh())
        self.gru = nn.GRU(hidden_dim, hidden_dim, num_gru_layers, batch_first=True, dropout=dropout)
        self.attention = FeatureAttention(hidden_dim)
        self.fusion_dim = hidden_dim * 4
        self.dropout = nn.Dropout(dropout)
        self.classifier = nn.Sequential(
            nn.Linear(self.fusion_dim, hidden_dim), nn.Tanh(),
            nn.Linear(hidden_dim, num_classes))

    def forward(self, x):
        encoded = self.encoder(x)
        gru_out, _ = self.gru(encoded)
        gru_last = gru_out[:, -1, :]
        attn_out = self.attention(gru_out)
        mul = gru_last * attn_out
        sum_ = gru_last + attn_out
        concat = torch.cat([gru_last, attn_out], dim=-1)
        fused = torch.cat([mul, sum_, concat], dim=-1)
        return self.classifier(self.dropout(fused))
